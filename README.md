# Schema Generator

Минимальный веб-инструмент для генерации JSON-LD Schema.org.

## Запуск

Откройте `index.html` в браузере.

## Что реализовано

- 3 зоны интерфейса: пресеты, типы, формы + вывод
- Live-генерация JSON-LD при любом изменении
- Пресет по умолчанию: **Общий head для всего сайта**
- `@graph` при нескольких типах
- Валидация критичных сущностей
- Исключение пустых сущностей
- localStorage для восстановления состояния
- Кнопка копирования кода
